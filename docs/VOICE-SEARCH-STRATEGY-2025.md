## 2. ESTRUCTURA DE CONTENIDO PARA FEATURED SNIPPETS

### Template de Respuesta Optimizada

**Formato Paragraph Snippet (40-60 palabras):**

```markdown
## ¿Qué es una SOFOM en México?

Una SOFOM (Sociedad Financiera de Objeto Múltiple) es una entidad financiera mexicana que otorga crédito, arrendamiento financiero y factoraje sin captar ahorro del público. A diferencia de los bancos, las SOFOMes se fondean con capital privado, lo que les da mayor flexibilidad para atender a PyMEs y sectores no bancarizados.
```

**Formato List Snippet:**

```markdown
## ¿Qué documentos necesito para constituir una SOFOM?

Los documentos esenciales son:

1. Acta constitutiva con opinión favorable de CONDUSEF
2. Identificación oficial de todos los socios
3. Comprobante de domicilio fiscal
4. RFC de la sociedad y de los socios
5. Dictamen técnico PLD/FT de la CNBV
6. Contrato con Buró de Crédito
7. Registro SIPRES en CONDUSEF
```

**Formato Table Snippet (comparativas):**

```markdown
## ¿Cuál es la diferencia entre SOFOM ER y SOFOM ENR?

| Característica | SOFOM ER | SOFOM ENR |
|---|---|---|
| **Regulación** | CNBV integral | CNBV solo PLD/FT |
| **Vínculo** | Con bancos/SOFIPOS | Sin vínculos |
| **Emisión valores** | Sí (RNV) | No |
| **Supervisión** | Prudencial completa | Compliance PLD |
| **Capital mínimo** | Variable (CNBV) | Sin mínimo legal |
```

**Formato Definition Snippet:**

```markdown
## ¿Qué es el dictamen técnico de la CNBV?

**El dictamen técnico CNBV es una autorización obligatoria** que evalúa si la SOFOM ENR cumple con las disposiciones de Prevención de Lavado de Dinero (PLD/FT). Se solicita después de constituir la sociedad y antes de iniciar operaciones. El plazo de respuesta es de 50 días naturales, y si no hay notificación, se considera aprobado por silencio administrativo.
```

```javascript
// faq-accordion.js - Accessible accordion for voice search
class FAQAccordion {
  constructor(container) {
    this.container = container;
    this.questions = container.querySelectorAll('.faq-question');
    this.init();
  }

  init() {
    this.questions.forEach(question => {
      question.addEventListener('click', this.toggle.bind(this, question));

      // Keyboard navigation
      question.addEventListener('keydown', (e) => {
        if (e.key === 'Enter' || e.key === ' ') {
          e.preventDefault();
          this.toggle(question);
        }
      });
    });
  }

  toggle(question) {
    const isExpanded = question.getAttribute('aria-expanded') === 'true';

    // Close all other accordions (optional: comment out for multi-expand)
    this.questions.forEach(q => {
      if (q !== question) {
        q.setAttribute('aria-expanded', 'false');
      }
    });

    // Toggle clicked question
    question.setAttribute('aria-expanded', !isExpanded);

    // Track with analytics
    if (!isExpanded && window.gtag) {
      const questionText = question.querySelector('h4').textContent;
      gtag('event', 'faq_expand', {
        event_category: 'FAQ',
        event_label: questionText,
        value: 1
      });
    }
  }
}

// Initialize
document.addEventListener('DOMContentLoaded', () => {
  const faqSection = document.querySelector('.faq-section');
  if (faqSection) {
    new FAQAccordion(faqSection);
  }
});
```

### Voice User Interface (VUI) Design

```javascript
// voice-assistant.js
class VoiceAssistant {
  constructor() {
    this.recognition = new webkitSpeechRecognition() || new SpeechRecognition();
    this.synthesis = window.speechSynthesis;
    this.init();
  }

  init() {
    this.recognition.lang = 'es-MX';
    this.recognition.continuous = false;
    this.recognition.interimResults = false;

    this.recognition.onresult = this.handleResult.bind(this);
    this.recognition.onerror = this.handleError.bind(this);
  }

  start() {
    this.recognition.start();
    console.log('Listening for voice command...');
  }

  handleResult(event) {
    const transcript = event.results[0][0].transcript.toLowerCase();
    console.log('User said:', transcript);

    // Match intent
    const intent = this.matchIntent(transcript);

    if (intent) {
      this.speak(intent.response.text);
      this.displayText(intent.response.text);
      this.showFollowUps(intent.response.followUp);
    } else {
      this.speak('Lo siento, no entendí tu pregunta. ¿Podrías reformularla?');
    }
  }

  matchIntent(transcript) {
    // Load intents from voice-bot-intents.json
    const intents = this.loadIntents();

    for (const intent of intents) {
      for (const utterance of intent.utterances) {
        if (transcript.includes(utterance)) {
          return intent;
        }
      }
    }

    return null;
  }

  speak(text) {
    const utterance = new SpeechSynthesisUtterance(text);
    utterance.lang = 'es-MX';
    utterance.rate = 0.9; // Slightly slower for clarity
    utterance.pitch = 1;

    this.synthesis.speak(utterance);
  }

  displayText(text) {
    const responseArea = document.getElementById('voice-response');
    if (responseArea) {
      responseArea.textContent = text;
    }
  }

  showFollowUps(followUps) {
    const container = document.getElementById('follow-ups');
    if (!container) return;

    container.innerHTML = '<p>También puedo ayudarte con:</p>';

    const list = document.createElement('ul');
    followUps.forEach(question => {
      const li = document.createElement('li');
      const button = document.createElement('button');
      button.textContent = question;
      button.onclick = () => {
        this.handleFollowUpClick(question);
      };
      li.appendChild(button);
      list.appendChild(li);
    });

    container.appendChild(list);
  }

  handleFollowUpClick(question) {
    // Simulate voice input
    this.handleResult({
      results: [[{ transcript: question }]]
    });
  }
}

// Initialize voice assistant
const voiceAssistant = new VoiceAssistant();

// Activate on button click
document.getElementById('voice-btn')?.addEventListener('click', () => {
  voiceAssistant.start();
});
```
